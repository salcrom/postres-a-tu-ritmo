# Postres a tu ritmo

PWA independiente con siete recetas recientes que todavía no estaban en
`Dulce a tu ritmo`. Incluye filtros, cantidades ajustables, procedencia,
instalación, uso sin conexión y aviso de actualización.

## Recetas de esta versión

- Rollos de canela con caramelo — adaptación de `@halikit25`.
- Cookies Ferrero Rocher — adaptación de `@bakerybynoelia`.
- Tarta fría de chocolate y plátano — adaptación de `@cookrate.cakes`.
- Rollos de canela Kinder Bueno — adaptación de `@haleza.food`.
- Tarta de mousse de chocolate — adaptación de `@blendymcblender`.
- Sobaos fritos con crema — adaptación de `@carnes_y_fuegos`.
- Cinnamon Roll Cheesecake — adaptación al sistema métrico de Savory Click
  Recipes.

Todas están marcadas como pendientes de prueba culinaria. No se reutilizan
fotografías ni vídeos de las fuentes.

## Comprobación

```bash
npm test
```

Para instalarla en iPhone, abrir la URL en Safari y usar **Compartir → Añadir a
pantalla de inicio**. Al existir una nueva versión, la PWA muestra el botón
**Actualizar PWA**.
